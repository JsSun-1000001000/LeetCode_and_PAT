## [面试题 16.01. 交换数字 - 力扣（LeetCode）](https://leetcode.cn/problems/swap-numbers-lcci/description/)

## 代码
```cpp
class Solution {
public:
	vector<int> swapNumbers(vector<int>& numbers) {
		numbers[0] = numbers[0] ^ numbers[1];
		numbers[1] = numbers[0] ^ numbers[1];
		numbers[0] = numbers[0] ^ numbers[1];
		return numbers;
	}
};
```
